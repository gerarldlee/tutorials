Delete Computer
{{computerToDelete.friendlyName && computerToDelete.friendlyName != '' ? computerToDelete.friendlyName : computerToDelete.name }}

This action will delete {{computerToDelete.friendlyName && computerToDelete.friendlyName != '' ? computerToDelete.friendlyName : computerToDelete.name }} and everything related to it.

Including:

  • Authentication keys - computer will not be able to connect to Deployify
  • Packages
  • Inventory
  • System information

Note that nothing will be changed on the actual computer.
